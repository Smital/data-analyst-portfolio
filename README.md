# Smital Christian — Data Analyst Portfolio Portfolio site

This folder contains a simple one-page portfolio website designed for GitHub Pages.

## Files
- `index.html` — portfolio content
- `styles.css` — styling

## Publish on GitHub Pages

1. Go to GitHub and create a **new public repository**.
2. Good repository name: `data-analyst-portfolio`
3. Upload `index.html` and `styles.css`.
4. Open the repository **Settings**.
5. Click **Pages** in the left menu.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select:
   - Branch: `main`
   - Folder: `/ (root)`
8. Click **Save**.
9. GitHub will generate your live portfolio URL after deployment.

## Customize

Edit `index.html` to update:
- About Me text
- Project descriptions
- GitHub links
- LinkedIn link
- Skills
- Location
